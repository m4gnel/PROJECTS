FLOW READING GUIDE
This document maps every screen, state, and decision path in the Agri-SAGE Android application. Read flows as: SCREEN NAME → [User Action] → NEXT SCREEN or [System Response].
Screen names are in CAPS and bold
User actions are in [Square Brackets]
System responses are in {Curly Braces}
Decision points are in <Angle Brackets> with YES/NO branches
Error states are marked ⚠

3. DIAGNOSE FLOW — CORE FEATURE
3.1 Full Diagnosis Journey
[SCREEN] DIAGNOSE START: Two options visible. '📷 Take a Photo' (large, primary). '🎤 Describe by Voice' (secondary). 'How this works' info link.
[Farmer taps 'Take a Photo']
[SCREEN] CAMERA SCREEN: Full-screen camera preview. Real-time quality indicator bar at top (GREEN = Good | YELLOW = Okay | RED = Improve). Guidance text changes based on quality: 'Move closer to the affected leaf' / 'Better lighting needed — move to shade' / 'Good — tap to capture'.
[SYSTEM] System: Run image quality check in real-time at 5fps using local ML. Laplacian variance, brightness histogram, crop region size.
[Farmer positions camera — indicator turns GREEN]
[Farmer taps capture button]
[SYSTEM] System: Capture image. Run quality check one final time. Check result:
<Image quality passes all thresholds? YES →> Save image to local storage. Show confirmation.
<Image quality fails? →>
[ERROR] ⚠ QUALITY REJECTION: Full-screen overlay with specific issue: 'This photo is too blurry. Please move closer and hold the phone steady.' Large retry button. Small 'Use anyway' option (adds warning flag to advisory).
[Farmer retakes or accepts]
[SCREEN] CONTEXT FORM: Shows auto-filled information with edit options. Crop: [Rice ▾] (dropdown — change if wrong). Growth Stage: [Tillering — Day 32 (estimated) ✎]. Location: [Thrissur, Kerala ✎]. Quick options (tap to toggle): Irrigated recently? | Fertilized recently? | Pesticide applied recently?. Optional: 'Add another photo' (up to 5). 'Analyze My Crop' button — large, green, prominent.
[Farmer confirms details, taps 'Analyze My Crop']
[SYSTEM] System: <Online? YES → Upload image → Start server-side advisory pipeline>. <Offline? → Run local ONNX vision → Use cached knowledge → Generate offline advisory>. Show progress screen.
[SCREEN] ANALYZING SCREEN: Crop illustration animation. Progress steps shown as they complete: ✓ Analyzing photo... | ✓ Checking weather... | ✓ Reviewing crop stage... | ⟳ Searching knowledge base...
→ Advisory generation complete (target: <8 seconds online, <3 seconds offline)
[SCREEN] ADVISORY RESULT SCREEN (full detail in Section 3.2)
3.2 Advisory Result Screen — Detailed Layout
[SCREEN] ADVISORY SCREEN — TOP SECTION: Confidence badge (LIKELY / POSSIBLE / etc.) in colored pill. Diagnosis name in large text. Local language name below in smaller text. Severity indicator: HIGH RISK / MEDIUM RISK / LOW RISK with color coding.
[SCREEN] ADVISORY SCREEN — EVIDENCE SECTION: 'Why we think this' expandable card (expanded by default). Evidence items as icon + text rows: 🌿 Leaf pattern matches rice blast | 🌧 3 wet days — favorable for disease | 🌾 Tillering stage — most susceptible | 📚 ICAR advisory confirms association.
[SCREEN] ADVISORY SCREEN — ACTION SECTION: Large action card with green border: WHAT: Apply Tricyclazole 75 WP fungicide | WHEN: Today before afternoon rain | HOW: Mix 0.6g per litre water | BEST TIME: 7:00am – 10:00am | COST: Rs.420 – Rs.540 per acre. 🔈 Voice button to read action aloud.
[SCREEN] ADVISORY SCREEN — SCENARIOS (if simulation available): 'Compare your options' section. 3 cards: A) Do nothing — Expected: 3,200 kg/ha* | B) Treat now ✓ Recommended — Expected: 5,100 kg/ha* | C) Wait 3-5 days — Expected: 4,400 kg/ha*. *Modelled estimate shown on each. Tap any card for detail.
[SCREEN] ADVISORY SCREEN — BOTTOM SECTION: 'What would change this?' expandable section. 'Schemes available' if any matched. Sources: 'Based on ICAR Rice Disease Advisory 2024 (Government Source)'. Was this helpful? 👍 👎 quick feedback.
3.3 Advisory States — Special Cases
[ERROR] ⚠ INSUFFICIENT_DATA STATE: 'We need more information.' Clear explanation of what's missing. Specific request: 'Please take another photo showing the whole plant and the affected area.' Retry button prominent.
[ERROR] ⚠ CONFLICTING_EVIDENCE STATE: 'We're not certain.' Two-column layout: What the image suggests vs What weather conditions suggest. 'Recommended: Have an expert look at this.' Escalation option shown.
[ERROR] ⚠ OUT_OF_SCOPE STATE: 'We don't support [crop] yet.' List of supported crops. 'Request this crop' button (sends feedback to team).
[ERROR] ⚠ OFFLINE STATE: 'Working offline — limited analysis.' Advisory clearly marked 'Offline Analysis'. Weather indicators not available. Cached knowledge advisory shown with 'For best results, connect to internet and re-analyze'.

9. NOTIFICATION & ALERT FLOWS
9.1 Morning Briefing Notification
[SYSTEM] System: Daily 6:00 AM — Monitoring Agent generates briefing for each active farmer. Checks: risk level, weather, crop stage, market changes. Sends FCM notification.
[SCREEN] NOTIFICATION (on phone lock screen): 'Good morning, Rajan 🌾 Your paddy is at tillering stage. Blast risk: Medium. Check lower leaves today.'
[Farmer taps notification]
→ Opens directly to MORNING BRIEFING DETAIL SCREEN (not home screen — deeplink)
[SCREEN] MORNING BRIEFING DETAIL: Full briefing card. Voice playback button at top. Crop summary. Risk analysis. Weather for the day. One recommended action. Market update if significant. 'Start my check' button → DIAGNOSE FLOW.
9.2 Risk Alert Notification
[SYSTEM] System: Monitoring Agent detects DFI > 0.7 AND crop at susceptible stage. Generates alert.
[SCREEN] NOTIFICATION: '⚠ Risk Alert — Your rice crop. Blast conditions are favorable. Inspect today.' Severity color: ORANGE for ATTENTION, RED for URGENT.
[Farmer taps notification]
→ Opens RISK ALERT DETAIL with full explanation and recommended action. One-tap to DIAGNOSE FLOW.
9.3 Notification Settings & Anti-Spam
Maximum 1 morning briefing per day per farm
Maximum 2 risk alerts per day per farm (highest priority only)
Spray window alerts only when there is an active diagnosis pending treatment
Market alerts only when price change > 10% from 7-day average
Quiet hours respected — no notifications between 9pm and 6am
Farmer can disable any notification type individually
10. VOICE FLOW
[SCREEN] VOICE INPUT ENTRY: Microphone button on diagnose start screen or keyboard + mic option on any text field. Malayalam language prompt. 'Tap and speak' instruction.
[Farmer taps mic, says 'എന്റെ നെല്ലിൽ ഇങ്ങനെ പാടുകൾ വന്നിട്ടുണ്ട്']
[SYSTEM] System: <Online? → Bhashini STT API call>. <Offline? → Android SpeechRecognizer>. Transcribe audio. Extract structured intent (crop, problem, location) — DO NOT pass raw transcript to LLM.
[SCREEN] TRANSCRIPT REVIEW: Shows transcription in Malayalam. Edit option if wrong. Detected intent shown: 'Crop: Rice | Problem: Spots on leaves'. 'Yes, that's right' / 'Let me correct this' options.
[Farmer confirms] → CONTEXT FORM pre-filled → DIAGNOSE FLOW continues
[SCREEN] VOICE OUTPUT: Speaker icon on every advisory screen. Plays TTS in farmer's selected language. Pause/resume. Speed control (0.75x / 1.0x / 1.25x). Background playback so farmer can walk field.

[SCREEN] PENDING STATE: 'Your query has been sent to an agronomist. You'll be notified when they respond — usually within 1 business day.' Return home option.

13. OFFLINE SYNC FLOW
[SYSTEM] System: All farmer actions while offline stored in sync_queue table (Room DB). Priority: 1=Observations, 3=Interventions, 5=Outcomes, 8=Feedback.
[SYSTEM] System: WorkManager SyncWorker monitors connectivity (ConnectivityManager). On network available → start sync.
[SCREEN] SYNC INDICATOR: Small sync icon in top bar animates while syncing. Disappears when done.
Step 1: Upload queued observations and images (highest priority)
Step 2: Upload intervention and outcome records
Step 3: Upload feedback and ratings
Step 4: Download updated weather, risk scores
Step 5: Download updated knowledge cache if version changed
Step 6: Download new scheme data if available
[ERROR] ⚠ SYNC CONFLICT: If same farm data changed on server and locally → server wins for profile data. Local observations are always preserved (append-only). User notified only if significant conflict.
[ERROR] ⚠ SYNC FAILURE: Exponential backoff — retry at 1min, 2min, 5min, 15min, 1hr. After 24 hours without sync, banner shown: 'Your data has not synced. Connect to internet when possible.'
