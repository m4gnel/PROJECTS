7. ACCESSIBILITY REQUIREMENTS
Minimum touch target: 48×48dp on ALL interactive elements — no exceptions per WCAG 2.1
Color contrast: minimum 4.5:1 for body text, 3:1 for large text (24sp+) against background
Color independence: color is NEVER the only indicator — always paired with icon OR text shape
TalkBack: every screen navigable with swipe/double-tap — all images have contentDescription
Focus order: logical reading order (top→bottom, left→right) enforced in Compose semantics
Font scaling: ALL text uses sp units — app works correctly up to 1.5× system font scale
Voice: every advisory screen has voice playback — app is usable by users who cannot read
Reduce motion: all animations respect system 'Reduce motion' / 'Remove animations' setting
Language: every string has Malayalam translation — no English fallback visible to Malayalam user
Error messages: always specific and actionable — never 'Error occurred' alone
⚠ Before any public release: conduct usability test with minimum 5 actual farmers with low digital literacy. Tests on developers' own devices are insufficient.
