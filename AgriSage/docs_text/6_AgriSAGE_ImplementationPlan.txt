Phase 2 — Task List
Task 2.1: Weather Agent
VSCode AI Agent Prompt:
✓ Create backend/agents/weather.py for Agri-SAGE. WeatherAgent.run(state) calls WeatherProvider to get current conditions and 7-day forecast for farm location. Derive ALL agricultural indicators: DFI (Disease Favorability Index) = weighted average of (humidity > 80% score) + (temperature 20-30°C score) + (consecutive_wet_days score), clamped 0-1. SprayWindow: rain probability < 20% AND wind < 15 km/h for any 4-hour block today — return best window time. IrrigationRecommendation: if rain > 10mm expected in 24hrs → 'skip', if soil dry estimate AND no rain → 'proceed', else 'delay'. HeatStressRisk: based on crop-specific temperature thresholds. Return WeatherResult with all indicators. Cache by (lat, lon) rounded to 2dp with 30-minute TTL using in-memory dict.
Task 2.2: Crop Stage Agent
VSCode AI Agent Prompt:
✓ Create backend/agents/crop_stage.py for Agri-SAGE. CropStageAgent.run(state) computes phenological stage using Growing Degree Days (GDD). GDD formula: ((Tmax + Tmin) / 2) - Tbase where Tbase is crop-specific (rice=10°C, maize=10°C, tomato=10°C, banana=15°C, coconut=20°C). Load historical weather from DB to compute cumulative GDD from planting_date to today. Compare against crop-cultivar GDD thresholds table (JSON file per crop defining: germination, seedling, tillering, panicle_initiation, flowering, grain_fill, maturity with GDD values). Return CropStageResult with: stage_name, gdd_accumulated, gdd_total_required (to maturity), disease_vulnerability (per stage-disease mapping JSON), upcoming_windows (next stage and estimated days). If farmer provided observed_growth_stage, use that to correct GDD estimate.
Task 2.3: Knowledge Ingestion Pipeline
VSCode AI Agent Prompt:
✓ Create backend/knowledge/ingestion.py for Agri-SAGE. DocumentIngestionPipeline class with: fetch_document(url) downloads PDF/HTML using httpx, parse_pdf(content) extracts text preserving tables using PyMuPDF (fitz), parse_html(content) extracts text using BeautifulSoup, extract_metadata(text, url) uses regex patterns to find crop mentions, state mentions, publication date, extract_chunks(text, metadata) does hierarchical chunking — split at heading boundaries first (H1/H2/H3 patterns), then at paragraph boundaries, max 512 tokens per chunk, min 100 tokens, preserve table rows intact, embed_chunks(chunks) calls multilingual-e5-large embedding model with 'passage: ' prefix per e5 convention, store_chunks(document_id, chunks, embeddings) bulk inserts into knowledge_chunks table. Script seed_knowledge.py: for each document URL in a seed_urls.json file, run the full pipeline.
Task 2.4: Hybrid RAG Retrieval
VSCode AI Agent Prompt:
✓ Create backend/knowledge/retrieval.py for Agri-SAGE. HybridRetriever class: dense_search(query_text, crop, state, top_k=15) embeds query with 'query: ' prefix using multilingual-e5-large, queries pgvector using SELECT ... ORDER BY embedding <=> query_vec WHERE crop=? AND status='PUBLISHED' AND valid_until > NOW() LIMIT top_k. sparse_search(keywords, crop, state, top_k=15) uses PostgreSQL full-text search: to_tsvector('english', content) @@ plainto_tsquery(:keywords). reciprocal_rank_fusion(dense_hits, sparse_hits, k=60) merges by RRF formula: score = sum(1/(k+rank)) per document. rerank(query, merged_hits, top_k=5) uses cross-encoder/ms-marco-MiniLM-L-6-v2 from sentence-transformers to score each chunk against query. apply_authority_boost(reranked): Tier 1 documents multiply score by 1.3. Return top_k chunks with source metadata.
Task 2.5: Knowledge Agent
VSCode AI Agent Prompt:
