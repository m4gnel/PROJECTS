# AgriSage Scroll-Sequence Frames Directory

Place your exported video JPEG frames in this folder.

### Recommended File Naming Convention:

`frame_001.jpg`, `frame_002.jpg`, `frame_003.jpg`, ... `frame_XXX.jpg`

(or `frame_1.jpg`, `frame_2.jpg`, etc.)

Once you drop your JPEG files into this folder, let me know how many frames you uploaded, and I will update the scroll-scrubbed canvas engine to seamlessly play through all your frames as you scroll!
